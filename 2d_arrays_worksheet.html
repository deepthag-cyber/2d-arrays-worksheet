Declaring a 2D Array

A 2D array organises data in rows and columns — like a table. Every cell is accessed using two indices: array[row][col].

Rows are the outer index; columns are the inner index. Counting starts at 0.
Pseudocode
DECLARE scores[3][4] : INTEGER

// Index map:
// scores[0][0]  scores[0][1]  scores[0][2]  scores[0][3]
// scores[1][0]  scores[1][1]  scores[1][2]  scores[1][3]
// scores[2][0]  scores[2][1]  scores[2][2]  scores[2][3]
Python
# Create a 3×4 2D list filled with zeros
scores = [[0] * 4 for _ in range(3)]

# Access: scores[row][col]
# e.g. scores[1][2]  →  row 1, column 2

Initialising a 2D Array

Initialisation means putting values into the array. You can do this by hard-coding values directly, or using a nested FOR loop to fill the array systematically.

Pseudocode — hard-coded
DECLARE grid[2][3] : INTEGER
grid[0][0] ← 10   grid[0][1] ← 20   grid[0][2] ← 30
grid[1][0] ← 40   grid[1][1] ← 50   grid[1][2] ← 60
Exercise 2.1 — Fill the grid after hard-coded initialisation
Pseudocode — nested FOR loop (fills 1 to 9)
DECLARE grid[3][3] : INTEGER
DECLARE i, j : INTEGER

FOR i ← 0 TO 2
    FOR j ← 0 TO 2
        grid[i][j] ← i * 3 + j + 1   // fills 1 to 9
    NEXT j
NEXT i
Python
grid = [[0] * 3 for _ in range(3)]
for i in range(3):
    for j in range(3):
        grid[i][j] = i * 3 + j + 1
print(grid)  # [[1,2,3],[4,5,6],[7,8,9]]

Populating a 2D Array with User Input

The nested loop asks the user for each cell one at a time. The outer loop picks the row; the inner loop picks the column.

Pseudocode
DECLARE marks[3][4] : INTEGER
DECLARE i, j : INTEGER

FOR i ← 0 TO 2
    FOR j ← 0 TO 3
        OUTPUT "Enter mark for row ", i, " col ", j
        INPUT marks[i][j]
    NEXT j
NEXT i
Python
ROWS, COLS = 3, 4
marks = [[0] * COLS for _ in range(ROWS)]

for i in range(ROWS):
    for j in range(COLS):
        marks[i][j] = int(input(f"Enter mark for row {i} col {j}: "))

for row in marks:
    print(row)

Bubble Sort on Each Row

Bubble sort is applied row by row. Each pass pushes the largest unsorted value to the right. A temp variable is used for the swap.

Pseudocode
DECLARE data[3][4] : INTEGER
DECLARE i, pass, k : INTEGER
DECLARE temp : INTEGER

// Assume data[][] is already populated

FOR i ← 0 TO 2                     // for each row
    FOR pass ← 0 TO 2              // 3 passes for 4 elements
        FOR k ← 0 TO 2 - pass      // window shrinks each pass
            IF data[i][k] > data[i][k+1] THEN
                temp          ← data[i][k]
                data[i][k]    ← data[i][k+1]
                data[i][k+1] ← temp
            ENDIF
        NEXT k
    NEXT pass
NEXT i
Python
data = [[4, 1, 3, 2],
        [9, 5, 7, 6],
        [2, 8, 1, 4]]
ROWS, COLS = 3, 4

for i in range(ROWS):
    for pass_ in range(COLS - 1):
        for k in range(COLS - 1 - pass_):
            if data[i][k] > data[i][k + 1]:
                data[i][k], data[i][k+1] = data[i][k+1], data[i][k]

for row in data:
    print(row)

Linear Search Across All Rows

The search scans every element row by row. A found flag tracks whether the target was located. All occurrences are reported.

Pseudocode
DECLARE data[3][3] : INTEGER
DECLARE i, j, target : INTEGER
DECLARE found : BOOLEAN

OUTPUT "Enter value to search:"
INPUT target
found ← FALSE

FOR i ← 0 TO 2
    FOR j ← 0 TO 2
        IF data[i][j] = target THEN
            OUTPUT "Found at row ", i, " col ", j
            found ← TRUE
        ENDIF
    NEXT j
NEXT i

IF found = FALSE THEN
    OUTPUT "Value not found"
ENDIF
Python
data = [[5, 8, 3],
        [7, 2, 6],
        [4, 9, 3]]

target = int(input('Enter value to search: '))
found = False

for i in range(len(data)):
    for j in range(len(data[i])):
        if data[i][j] == target:
            print(f"Found at row {i} col {j}")
            found = True

if not found:
    print("Value not found")
