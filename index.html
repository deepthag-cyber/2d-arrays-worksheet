1 · Declaring a 2D Array

A 2D array stores data in rows and columns like a table. Every cell is accessed using Array[Row, Col]. Rows are the outer index; columns the inner — both start at 0.

Pseudocode
DECLARE Scores : ARRAY[0:2, 0:3] OF INTEGER

// Scores[0,0] Scores[0,1] Scores[0,2] Scores[0,3]
// Scores[1,0] Scores[1,1] Scores[1,2] Scores[1,3]
// Scores[2,0] Scores[2,1] Scores[2,2] Scores[2,3]
Python
Scores = [[0] * 4 for _ in range(3)]
# Scores[row][col] — e.g. Scores[1][2]

2 · Initialising a 2D Array

Values can be placed into the array by hard-coding them directly, or by using a nested FOR loop to fill cells systematically.

Pseudocode — hard-coded
DECLARE Grid : ARRAY[0:1, 0:2] OF INTEGER
Grid[0,0]←10  Grid[0,1]←20  Grid[0,2]←30
Grid[1,0]←40  Grid[1,1]←50  Grid[1,2]←60

Pseudocode — nested FOR (fills 1 to 9)
DECLARE Grid : ARRAY[0:2, 0:2] OF INTEGER
DECLARE I, J : INTEGER
FOR I ← 0 TO 2
    FOR J ← 0 TO 2
        Grid[I,J] ← I * 3 + J + 1
    NEXT J
NEXT I

3 · Populating with User Input

The nested loop asks the user for each cell one at a time. The outer loop picks the row; the inner loop picks the column.

Pseudocode
DECLARE Marks : ARRAY[0:2, 0:3] OF INTEGER
DECLARE I, J : INTEGER
FOR I ← 0 TO 2
    FOR J ← 0 TO 3
        OUTPUT "Enter mark for row ",I," col ",J
        INPUT Marks[I, J]
    NEXT J
NEXT I
Python
Marks=[[0]*4 for _ in range(3)]
for I in range(3):
  for J in range(4):
    Marks[I][J]=int(input(
      f"Row {I} Col {J}: "))

4 · Bubble Sort Each Row

Uses REPEAT…UNTIL with a Swap flag — exits early if no swaps occurred, making it more efficient than a fixed-pass loop.

Pseudocode — bubble sort each row
DECLARE Data : ARRAY[0:2, 0:3] OF INTEGER
DECLARE I, Index, Last : INTEGER
DECLARE Temp : INTEGER
DECLARE Swap : BOOLEAN

FOR I ← 0 TO 2
    Last ← 3
    REPEAT
        Swap ← FALSE
        FOR Index ← 0 TO Last - 1
            IF Data[I, Index] > Data[I, Index+1]
            THEN
                Temp             ← Data[I, Index]
                Data[I, Index]   ← Data[I, Index+1]
                Data[I, Index+1] ← Temp
                Swap ← TRUE
            ENDIF
        NEXT Index
        Last ← Last - 1
    UNTIL (NOT Swap) OR Last = 0
NEXT I
Python
Data=[[4,1,3,2],[9,5,7,6],[2,8,1,4]]
for I in range(3):
  Last=3
  while True:
    Swap=False
    for Index in range(Last):
      if Data[I][Index]>Data[I][Index+1]:
        Data[I][Index],Data[I][Index+1]=\
          Data[I][Index+1],Data[I][Index]
        Swap=True
    Last-=1
    if (not Swap) or Last==0:break

Challenge — Adapt the sort

Task: Write pseudocode to sort only the first row (row 0) of a 2×5 array called Nums : ARRAY[0:1, 0:4] in ascending order using the REPEAT…UNTIL bubble sort. No need to sort row 1.


No outer FOR I loop needed — fix I=0. Last starts at 4 (last valid index). REPEAT…UNTIL (NOT Swap) OR Last=0.

Model Answer

DECLARE Nums : ARRAY[0:1, 0:4] OF INTEGER
DECLARE Index, Last, Temp : INTEGER
DECLARE Swap : BOOLEAN
Last ← 4
REPEAT
    Swap ← FALSE
    FOR Index ← 0 TO Last - 1
        IF Nums[0, Index] > Nums[0, Index+1] THEN
            Temp            ← Nums[0, Index]
            Nums[0, Index]  ← Nums[0, Index+1]
            Nums[0, Index+1] ← Temp
            Swap ← TRUE
        ENDIF
    NEXT Index
    Last ← Last - 1
UNTIL (NOT Swap) OR Last = 0

5 · Linear Search Across All Rows

Scans every element row by row. A Found flag tracks whether the target was located. All occurrences are reported.

Pseudocode
DECLARE Data : ARRAY[0:2, 0:2] OF INTEGER
DECLARE I, J, Target : INTEGER
DECLARE Found : BOOLEAN
OUTPUT "Enter value to search:"
INPUT Target
Found ← FALSE
FOR I ← 0 TO 2
    FOR J ← 0 TO 2
        IF Data[I, J] = Target THEN
            OUTPUT "Found at row ", I, " col ", J
            Found ← TRUE
        ENDIF
    NEXT J
NEXT I
IF Found = FALSE THEN
    OUTPUT "Value not found"
ENDIF
Python
Data=[[5,8,3],[7,2,6],[4,9,3]]
Target=int(input("Search: "))
Found=False
for I in range(3):
  for J in range(3):
    if Data[I][J]==Target:
      print(f"Found at {I},{J}")
      Found=True
if not Found:
  print("Not found")
